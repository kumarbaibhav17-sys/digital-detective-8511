## Task 1.1 Trace one activity using IPOS

| Stage | What happens in my example | Hardware / component |
|---|---|---|
| Input | I type text on the keyboard | Keyboard |
| Processing | The computer turns key presses into characters and shows them in the document | CPU and memory (RAM) |
| Output | The text appears on the screen as I type | Screen |
| Storage | I press save and the file is written to the computer | SSD / hard disk |

## Task 1.2: Hardware and software

| Item / software name | Hardware or software? | Software type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Used to enter text |
| Screen | Hardware | Not applicable | Displays text, images and videos |
| SSD | Hardware | Not applicable | Stores files and programs permanently |
| Trackpad / mouse | Hardware | Not applicable | Moves the pointer and selects items |
| macOS | Software | Operating system | Manages the hardware and runs other programs |
| VS Code | Software | Application | Used to write and edit code and README files |
| Chrome / Safari | Software | Application | Used to browse websites |
| Activity Monitor | Software | Utility | Shows running programs and how much memory and CPU they use |
