# The Digital Detective

## Introduction
This repository contains my Diwali independent learning assignment, "The Digital Detective". I explored how my computer works, practised Terminal commands, learned about the operating system, programs, number systems, Git and GitHub, and computer networks.

- Input, processing, output and storage (IPOS), hardware and software
- Terminal commands, flags and pipes
- Operating system, processes, paths and permissions
- Compilers and interpreters
- Binary, decimal and hexadecimal numbers and text encoding
- Git, branches and Pull Requests
- Networks, DNS and how a website opens
